# Krydsord: uden vægge, version 1

Gemte layout og UI før forsøget med flere krydsninger. 61 ord, 24 × 28 felter. Originalfiler og SHA-256 findes i manifest.json; preview.png viser layoutet.

For kun at gendanne ordplaceringen: kopiér server/data/crossword.ts fra denne mappe tilbage til projektets server/data/crossword.ts. De øvrige filer er gemt til sammenligning og fuld UI-gendannelse. Kontrollér at konkurrencen ikke er åbnet, før løsningen ændres. Kopiér aldrig lokal spilstatus, vindere eller wallets tilbage; databasen er ikke en del af dette designsnapshot.
