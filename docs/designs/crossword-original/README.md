# På Tværs #1 · vinderens profilpynt

Banner og profilramme er eksklusive ekstra præmier til den første korrekte løsning. Den eksisterende præmie med RTA-kop, 1.000 bananer og vinderbadge bevares. En tidligere betalt vinder får også de nye kosmetiske præmier ved næste afregning, uden ny bananudbetaling. Begge kan vælges under profilindstillinger.

Genereret med den indbyggede ImageGen. PNG-originaler: `winner-banner.png` og `winner-frame.png`. WebP-filer og portrætmaske: `public/games/crossword/original/`.

Bannerprompt: Fjern kun ORIGINALEN og PÅ TVÆRS #1 samt de korte streger ved overskriften fra referencebanneret. Bevar grøn tekstur, elfenbensfarvede krydsordsfelter, guldbånd, laurbær og 1-medaljonen. Ingen ny tekst.

Rammeprompt: Rund profilramme i samme stil med elfenbensfarvede krydsordsfelter, champagneguldkant, mørkegrønne detaljer og en lille 1-medaljon med laurbær nederst. Ingen overskrift. Ægte transparent portræthul og yderside.

Portrætmasken følger hele den sammenhængende åbning, så profilbilledet dækker uden mørk kant og uden at vise sig uden for rammen.
