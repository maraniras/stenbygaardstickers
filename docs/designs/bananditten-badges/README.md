# Bananditten – x84–x88

2. november 2026. Fem egne 3D-motiver genereret med indbygget image_gen, transparent baggrund og uden Emil. De fulde fælles krav og individuelle prompts findes i [prompts.json](prompts.json). PNG-originalerne ligger her; appen bruger alpha-bevarende WebP-filer optimeret med `node scripts/install-badge-art.mjs docs/designs/bananditten-badges` i `public/badges/custom/`.

| Nr. | Motiv | Fil |
|---|---|---|
| x84 | Lilla/guld-spilleautomat med bananer og håndtag | slot-spins |
| x85 | Bananer, jetoner og grønne gevinstpile | slot-wins |
| x86 | Minevogn med bananguld | slot-big-wins |
| x87 | Kronet guldbanan med laurbær og trofæfod | slot-jackpot |
| x88 | Tre jetoner med grønne flueben og en forbindende pil | slot-streak |

Alle motiver er visuelt kontrolleret og installeret direkte i appen. Trinfarverne kommer fortsat fra medaljekanten. Faste numre, tærskler, belønninger og point står i `docs/badges.md`. Alle fem er aktive; ingen generelle casino-badges er tilføjet.
