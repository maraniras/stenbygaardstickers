# Pakkeleg – gaveikoner

Lavet med built-in imagegen. Præcise prompts findes i [prompts.json](prompts.json). Originale PNG-filer bevares her som `*-v1.png`; optimerede, transparente 384 px WebP-filer bruges af appen:

- `public/games/parcels/golden-gift.webp` – gylden banangave, 500 bananer.
- `public/games/parcels/exclusive-frame.webp` – eksklusiv cirkulær juleprofilramme med transparent center.
- `public/games/parcels/rta-snowglobe.webp` – symbolsk RTA-snekugle, fysisk præmie + 50 bananer.

Genbrugte juleikoner fra `public/games/advent/`: Mix Max, cykeldrikkedunk, drillenisse samt enkelt banan/lille og stor bananbunke. De genbrugte filer og deres oprindelige designarkiv er bevaret.

Gavernes indpakning er uafhængig af indholdet. Ikoner vises først efter, at ejeren selv har åbnet pakken. En vundet profilramme gemmes på brugeren og vises med UserAvatar.
