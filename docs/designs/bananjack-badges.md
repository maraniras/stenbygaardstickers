# Bananjack: otte badgemotiver

Genereret med indbygget image_gen den 30. oktober 2026. Originale PNG-filer, `oversigt.png` og `index.html` ligger i `bananjack-badges/`. Appikoner ligger som optimeret WebP i `public/badges/custom/`, klar via `badgeIcon()`. Installeret efter visuel kontrol med `node scripts/install-badge-art.mjs docs/designs/bananjack-badges`.

x76–83 er nu aktive med statistik, point, belønninger, profilvisning og den fælles notifikationslogik. Den aftalte tabel står i `docs/badges.md`; generelle casino-badges er ikke med i dette sæt. Trinmotiverne bruger appens eksisterende farvede medaljekanter, ikke indbyggede tier-kanter i billedet.

## Fælles prompt og referencer

Use case: stylized-concept. ONE production-ready standalone 3D achievement icon for Stenbygaard Stickers Bananjack collection. Identity reference `branding/logo.png`: exact recognizable shouting brown-haired Emil profile printed on cream/gold-edged sticker, one face total. Material/style reference ONLY `legacy-badges-preview-10/jubilee.png`, not rosette/star/confetti composition. Polished rich purple enamel, warm gold/brass, cream and mint accents, tactile playful premium 3D, soft studio light. Compact bold readable 64px silhouette, square with 8% transparent padding, fully contained, genuine alpha. No backdrop, floor, floor shadow, outer medal ring, tier ring, watermark or title. No text/digits except explicitly requested card ranks. No full human body or extra faces. Separate image_gen call per motif, transparent_background=true.
