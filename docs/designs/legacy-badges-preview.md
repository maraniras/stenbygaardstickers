# Prøvesæt: seks klassiske badges

Genereret med den indbyggede image_gen den 30. oktober 2026. Alle seks motiver er nu i brug i appen som optimerede WebP-filer i `public/badges/custom/`.

Identitetsreference: `branding/logo.png`. Stilreference: `docs/designs/custom-badges-reference.png`. Én separat generering pr. motiv, med ægte gennemsigtig baggrund.

## Fælles prompt

Premium, detailed playful 3D achievement icon for Stenbygaard Stickers. Preserve the distinctive recognizable brown-haired shouting profile of Emil from the supplied logo. Match the existing game badge reference: polished purple enamel, warm brass/gold, cream and mint accents, tactile materials, soft studio lighting. One standalone motif, centered, fully contained with 8 percent transparent padding and a strong silhouette readable at medal size. Genuine alpha. No background rectangle, text, numbers, watermark, outer medal ring or cast floor shadow.
