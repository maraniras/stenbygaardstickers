# Prøvesæt 2: seks klassiske badges

Genereret med den indbyggede image_gen den 30. oktober 2026. Individuelle PNG-filer med original alpha findes i `docs/designs/legacy-badges-preview-2/`. Alle seks motiver er nu i brug i appen som WebP-filer i `public/badges/custom/`. Badgereglerne er uændrede.

## Referencer og fælles prompt

Identitet: `branding/logo.png`. Stil: `docs/designs/legacy-badges-preview/oversigt.png`. Én generering pr. motiv med transparent_background=true.

Use case: stylized-concept. One standalone premium achievement icon for Stenbygaard Stickers. Preserve Emil's exact recognizable brown-haired shouting profile and expression from the supplied logo as the sticker print. Match the reference's richly detailed playful polished 3D, tactile vinyl/enamel, warm gold/brass and purple accents, and studio lighting. New motif, not a copy of an existing motif. Fully contained square composition, 8% transparent padding, silhouette readable at 64px. Genuine alpha, no floor shadow, background rectangle, text, letters, digits, watermark or outer medal ring. Keep the face recognizable, not a generic cartoon man.
