# Daglige byer

Navne: [GeoNames countryInfo](https://download.geonames.org/export/dump/countryInfo.txt), hentet 29. oktober 2026, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Danske navne er tilpasset. Koordinaterne er fra appens eksisterende hovedstadsdata i `shared/utils/capitals.ts`.
Et udvalg uden flertydige/overgangs-hovedstæder indgår. `scripts/make-daily-cities.mjs` genskaber `daily-cities.json` fra kildedata.

Luftfoto: Esri World Imagery (Esri, Maxar, Earthstar Geographics), samme baggrund som appens kort. Ingen stednavnelag. Billeder hentes fra den offentlige export-tjeneste med attribution i spillet.
